# Databases in the Age of AI

A long-form essay on what happens to the fifty-year-old discipline of database systems when the dominant reader of data is no longer human.

**Read it:** https://zozo123.github.io/databases-in-the-ai-era/

Seven chapters:

1. **The Reader Changes** — the 80%-agent-provisioned-databases moment, and the Petrov framing
2. **One Correct Answer** — what Anthropic's self-service analytics post actually measured (21% → 95% with curated context)
3. **The Physics Doesn't Care** — storage engines, vector indexes, learned indexes, and disaggregation through the *Database Internals* lens
4. **Git for Data** — Neon/Lakebase, copy-on-write branching, MCP, agent memory, and the database-as-disposable-artifact
5. **The Meaning Moat** — the catalog wars: Unity Catalog, Polaris, dbt×Fivetran, and why semantics is an organizational achievement
6. **Stress-Testing the Bull Case** — six complications for the "Databricks explodes" thesis
7. **The Last Human Query** — ten dated, falsifiable predictions for 2027–2034
