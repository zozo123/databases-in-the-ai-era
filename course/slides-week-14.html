Lecture 1 · Tuesday

Fifty Years of Data-Model Rebellions

Stonebraker wrote the same paper twice, nineteen years apart. Both times he was right.

L1 · The Cycle

The paper written twice

  • 2005: What Goes Around Comes Around — 35 years surveyed.
  • 2024 sequel with Pavlo, SIGMOD Record 53(2).
  • Extends through MapReduce, NoSQL, document, graph.
  • Finding: the cycle is still turning.
L1 · The Cycle

You can set a tenure clock by it

  • New workload exposes a real relational weakness.
  • Rebellion declares SQL dead, ships new model + language.
  • Spends a decade rediscovering transactions, schemas, optimization.
  • SQL absorbs the one new thing — a type and an index.
  • Rebellion survives as niche engine or Postgres column.
L1 · Lap One

Codd’s rebellion-that-stuck

  • IMS (1968) = trees; CODASYL (1969) = pointer networks.
  • Programmers navigate: GET NEXT WITHIN PARENT loops.
  • Change the layout → rewrite the application.
  • Codd 1970: data independence — name data, system navigates.
  • Scoring question ever since: did you give up data independence?
L1 · Lap Two

Objects: the impedance mismatch

  • OODB wave: GemStone, ObjectStore, O2; ODMG standard 1993.
  • Persist C++ objects directly — skip the tables.
  • Gave up declarative queries and the schema boundary.
  • Database now breaks when you refactor.
  • Verdict by 2000: a rounding error; SQL:1999 added structured types.
L1 · Lap Three

XML: the purest specimen

  • Had everything vectors have now: mandates, W3C stack, VC engines.
  • Claim: this time the data really is different.
  • Counter-move: SQL/XML (2003) type + XML indexes.
  • The type survived; the universal data model did not.
  • JSON re-ran the loop fast-forward: SQL:2016 operators, SQL:2023 type.
L1 · Lap Four

MapReduce rebelled against the engine

  • Google 2004: no schema, no indexes, no optimizer — just scale.
  • DeWitt & Stonebraker 2008: “major step backwards.” Mostly correct.
  • Within five years: Hive, Impala, Presto, SparkSQL rebuilt SQL.
  • Residue: shared-nothing scale-out, storage/compute split.
L1 · Lap Five

NoSQL: the decade of rediscovering ACID

  • MongoDB 2009: no joins, no transactions, no schema.
  • 2012: aggregation pipeline. 2015: $lookup join.
  • 2018: multi-document ACID in 4.0, plus schema validation.
  • Google’s answer to Bigtable: Spanner — serializable, SQL by 2017.
  • The rebels did not lose; they converged.
L1 · The Asymmetry

Why the cycle always closes

≈10y vs 2

a rebellion needs ~ten years to rebuild recovery, concurrency, statistics, drivers, a planner — the incumbent bolts the one good idea into a socket in ~two release cycles.

The “native XML” policy store

Lecture 2 · Thursday

Final Debate: the First Genuine Exception?

Resolved: vectors, semantic operators, and agent memory are the next XML.

L2 · The Resolution

Steelman, don’t strawman

  • Two teams, twenty minutes a side.
  • Argue the strongest version of the position you draw.
  • If absorption wins: go write Postgres extensions and optimizer rules.
  • If exception wins: write the System R paper of the agentic era.
L2 · Absorption

Exhibit one: pgvector

18 months

pgvector 0.5 shipped HNSW in 2023; within a year Oracle, SQL Server, MySQL, DuckDB, and the cloud warehouses all had a vector type and an ANN index — the XML choreography, executed in eighteen months instead of ten years.

L2 · Absorption

Exhibits two and three

  • SQL/PGQ: graph absorbed into the 2023 standard.
  • Absorbed while the debate was still running.
  • Vector DBs already pivoting to “AI data platforms.”
  • Semantic operators = expensive UDFs.
  • WHERE llm_judge(review, …) — scalar function, weird cost.
  • Hellerstein costed expensive predicates in the early 1990s.
L2 · Absorption

Three “dead” rebellions, one statement

-- 2026, one engine, one statement
SELECT p.sku, p.meta->>'title' AS title,
       embedding <=> :query_vec AS dist
FROM   products p
WHERE  p.meta @> '{"status":"active"}'   -- the JSON rebellion
ORDER  BY embedding <=> :query_vec        -- the vector rebellion
LIMIT  20;                                -- HNSW scan, costed like any other

Agents speak SQL through MCP — we taught the new client the old language.

L2 · Exception

1. Accuracy is now in the result

  • B-tree lookup and hash join return the same tuples.
  • HNSW: recall@10 ≈ 0.95 at one ef_search, ≈ 0.99 at another.
  • The higher setting costs 3–5× the latency.
  • The answer itself is now a knob. XML never did this.
  • SQL has no syntax for “95% of the right rows is fine.”
L2 · Exception

2. Operators now cost dollars

$7,500

one semantic join over a 10⁴ × 10⁴ pair space = 10⁸ model calls ≈ $7,500 for a single query. Plan choice is now a procurement decision.

L2 · Exception

The arithmetic, per row

  • Conventional predicate: ~10 ns CPU ≈ 10−12 dollars.
  • Semantic predicate: ~300 tokens × $0.25/M ≈ $7.5×10−5 per row.
  • Gap: seven to eight orders of magnitude, before latency.
  • Not “an expensive predicate” — cost avoidance under a budget.
  • Different problem, different APIs: budgets, previews, partial results.
L2 · Exception

3. The algebra is no longer closed

  • Classical rewrites are sound: change cost, never answers.
  • Semantic operator: (relation, prompt, model-version, temperature) → distribution.
  • Push a predicate below a semantic filter → the model sees different rows.
  • The rewrite changes the answer, not just the cost.
  • Every optimizer rule now needs an accuracy-preservation proof.
L2 · Field Note

The index that disagreed with itself

4%

a silent model-version bump flipped 4% of cached semantic-filter verdicts — and a downstream aggregate a procurement agent acted on. The fix: pin model versions like schema versions; treat an upgrade as a migration with a backfill.

L2 · Refereeing

Three tripwires, five years

  • SQL grows WITH RECALL 0.95 CONFIDENCE 0.9 → absorption.
  • That would be its biggest concession since windows in SQL:2003.
  • Agent traffic moves to beliefs + provenance → exception.
  • Then relational ends like navigational: underneath, not the interface.
  • Neither happens → the cycle turns; you teach lap eight.
L2 · Thesis

The course thesis, restated

  • Agents are the dominant clients; workloads change, not physics.
  • Physics held: B-trees, ARIES, MVCC, buffer pool, optimizer.
  • Workloads changed everywhere we measured.
  • What’s scarce: agreement on meaning, not throughput.
  • Fifty years of agreement on values; the frontier is meaning.
L2 · Open Problems

Three problems worth a PhD

  • Agent-native TPC: correct-task-completions per dollar, under retry storms.
  • Derived-belief isolation: name the anomalies, then the protocols.
  • Recall-aware compaction: lossy forgetting with stated recall guarantees.
  • All systems problems; none needs a new model architecture.
  • Durable contributions are contracts and machinery, not models.
Every rebellion thought it was killing SQL. Every rebellion ended as a column type and an access method.
